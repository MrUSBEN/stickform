# objects/

Props for scenes: GLB, GLTF (self-contained) or OBJ files. Everything here is listed in the Scene card's
**+ Add** menu and in the Objects tab next to Presets. Importing a file with **+ Add › Object from file…** offers to
keep a copy here, and scene files that use an object find it here by its file name.

Sizes are read in metres; a file that looks like centimetres (or kilometres) comes in at a guessed scale, which
you can change with Scale in the Pose card (Reset turn and size goes back to the guess).

The folder starts empty and its contents are never committed to the repository.
